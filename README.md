# food-ai-content-bot

Внутренний Telegram-бот для администратора канала о еде, семье, готовке и AI.

Главный сценарий: администратор отправляет фото блюда, бот анализирует фото через OpenAI Vision, генерирует готовый Telegram-пост, показывает черновик с кнопками редактирования и публикует фото с текстом в канал после подтверждения.

## Возможности

- Доступ только для `ADMIN_ID`.
- Команды: `/start`, `/help`, `/post`, `/reels`, `/plan`, `/style`, `/publish`, `/cancel`.
- `/post`: генерация Telegram-поста по фото блюда.
- Inline-кнопки для черновика: публикация, переписывание, более семейный/шефский/AI/полезный стиль, короче, эмоциональнее, отмена.
- `/reels`: сценарий Reels по фото или текстовому описанию.
- `/plan`: контент-план на 7 дней.
- `/style`: выбор базового стиля генерации.
- Хранение последнего черновика в памяти процесса без PostgreSQL.
- Railway-ready запуск через `python bot.py`.

## Структура файлов

```text
.
├── bot.py            # основной код Telegram-бота
├── requirements.txt  # зависимости Python
├── runtime.txt       # версия Python для Railway
├── Procfile          # worker-процесс для Railway/Heroku-style платформ
├── railway.json      # Start Command для Railway
├── .env.example      # пример локальных env-переменных
└── README.md         # инструкция по запуску и деплою
```

## Переменные окружения

Обязательные:

- `BOT_TOKEN` — токен Telegram-бота из BotFather.
- `OPENAI_API_KEY` — ключ OpenAI API.
- `ADMIN_ID` — Telegram user ID администратора. Должен быть числом.
- `CHANNEL_ID` — ID канала или username канала, например `@my_food_channel`.

Опциональная:

- `OPENAI_MODEL` — модель OpenAI для Vision и генерации текста. По умолчанию используется `gpt-4o-mini`.

## Локальный запуск

1. Установите Python 3.11.
2. Создайте виртуальное окружение:

```bash
python3.11 -m venv .venv
source .venv/bin/activate
```

3. Установите зависимости:

```bash
pip install -r requirements.txt
```

4. Создайте `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

5. Заполните `BOT_TOKEN`, `OPENAI_API_KEY`, `ADMIN_ID`, `CHANNEL_ID`.
6. Запустите бота:

```bash
python bot.py
```

## Деплой на Railway

1. Создайте новый проект Railway из GitHub-репозитория.
2. Убедитесь, что Railway видит Python-проект, `requirements.txt` и `runtime.txt` с Python 3.11.9.
3. В Variables добавьте:
   - `BOT_TOKEN`
   - `OPENAI_API_KEY`
   - `ADMIN_ID`
   - `CHANNEL_ID`
4. Start Command уже задан в `railway.json`:

```bash
python bot.py
```

5. Задеплойте сервис и проверьте логи. При отсутствии обязательных переменных бот завершится с понятной ошибкой.

## Как добавить бота админом в канал

1. Откройте Telegram-канал.
2. Перейдите в настройки канала → Administrators / Администраторы.
3. Нажмите Add Admin / Добавить администратора.
4. Найдите своего бота по username.
5. Дайте право публиковать сообщения.
6. В `CHANNEL_ID` укажите `@username` публичного канала или числовой ID приватного канала.

## Как проверить публикацию

1. Напишите боту `/start` от аккаунта администратора.
2. Выполните `/post`.
3. Отправьте фото блюда.
4. Дождитесь черновика.
5. Нажмите `🚀 Опубликовать` или выполните `/publish`.
6. Проверьте, что в канале появилось исходное фото с текстом.

Если публикация не удалась, проверьте:

- корректность `CHANNEL_ID`;
- что бот добавлен в канал;
- что бот является администратором;
- что у бота есть право публиковать сообщения.

## Безопасность

Бот не предназначен для обычных пользователей. Если пишет не администратор из `ADMIN_ID`, бот отвечает: `Бот доступен только администратору.`
